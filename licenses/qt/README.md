For the inspected PySide6/Shiboken distributions, this project selects the GPL-3.0-only option. LGPL text and the Qt GPL exception are supplied for reference and applicable component-specific terms; the presence of a text does not mean it licenses every bundled file. BSD/Apache notices and attributions must also be preserved where applicable.

These core texts alone are NOT a complete set of third-party attributions. Windows packaging additionally gathers LICENSES, copyright/notice files and qt_attribution.json from the exact version-tagged Qt modules identified in the frozen DLL inventory and from pyside-setup, and includes full source archives to preserve source-header attributions. See qt-license-provenance.json, qt-open-source-notices and qt-source-evidence in the build's legal evidence.

The commercial-license alternative is not used as evidence for the GPL route. Source-version matching does not prove that vendor wheels contain no patches or additional native libraries; inspect the frozen inventory and wheel build provenance.
